Formulários

— Método POST:

A informação submetida pelo formulário será enviada para o servidor dentro do corpo do pedido. É como se os dados fossem inseridos dentro de uma caixa e enviados para o servidor juntamente com outras informações da página.

— Método GET:

Com este método os dados serão enviados atravez do endereço do "action".

Ao endereço especificado no "action", o HTML irá adicionar um conjunto de informações que contém o nome de cada campo e seus respectivos valores. Dessa forma é possível ver o que está cendo transmitido pelo navegador.
