— Após a instalação do Python, no Windows, abra o PowerShell e verifique a "ExecutionPolicy":
    
    1. Verificar o modo atual:
        
        Get-ExecutionPolicy
        
            ↪ Por padrão retornará: Restricted
    

    2. Altere para "RemoteSigned":

        Set-ExecutionPolicy RemoteSigned -Force


    3. Criar um ambiente virtual para teste:

        python -m venv venv

        3.1. Ativar o ambiente virtual:

            .\venv\Scripts\activate
